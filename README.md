# 屏幕区域标识自动计数器

盯住屏幕上的一块区域，识别其中是否出现某个特定标识，出现一次就自动 +1。
典型场景：游戏里某个提示/图标/文字出现次数统计、界面元素出现频次记录。

## 特性

- **两种计数模式**：出现即计数（上升沿，防重复）/ 统计可见数量（多点匹配 + 峰值记录）
- **冻结帧框选**：进入框选时先抓一帧静态快照，拖拽框选、拖动选区、八向手柄微调，交互对齐系统截图工具
- **模板同源**：默认在「监测区域的冻结帧」上裁切模板，与运行时抓帧同源同尺度；也可切换为整屏任意位置截取
- **防重复计数**：连续确认帧 + 迟滞阈值 + 冷却时间，同一标识持续显示只算一次
- **不挡视野**：迷你模式（右上角小条）/ 窗口最小化（计数继续，数字显示在任务栏标题）/ 可取消置顶
- **遮挡告警**：画面长时间无变化或纯色时状态栏提示，避免"以为在计数其实早停了"
- 相似度阈值、检测间隔、多尺度匹配、提示音、全局热键可调；事件落盘 `counter_log.csv`

## 安装

```bash
pip install opencv-python mss Pillow keyboard numpy
```

> 注意：需要带 **tkinter** 的 Python（部分精简发行版没有）。

## 运行

```bash
python screen_counter.py
```

自检（无界面）：

```bash
python screen_counter.py --selftest      # 匹配/状态机/选区器/界面构建
python screen_counter.py --capturetest   # 模板截取全链路
python screen_counter.py --tpltest       # 模板来源切换 + 尺寸/跨屏校验
python screen_counter.py --mintest       # 最小化期间是否仍在计数
```

生成桌面快捷方式（需要 `pywin32`）：

```bash
python make_shortcut.py
```

## 使用步骤

1. 让屏幕上出现你要监测的标识
2. 点「① 框选监测区域」→ 在冻结帧上拖拽框出范围
3. 点「② 截取标识模板」→ 框住**标识本身**（越紧凑越准）
4. 点「开始监测」→ 标识出现即计数 +1，事件写入 `counter_log.csv`

> 想少点一步：把「模板来源」切到**整屏任意位置**，②按钮会变成「② 框选区域+模板」，
> 框一次即同时定下监测区域与模板。

### 模板来源（两种，可切换）

| 来源 | 行为 | 适用 |
|---|---|---|
| 监测区域内（默认，推荐） | 先①框监测区域，再②在监测区域的冻结帧上裁切标识 → 与运行时抓帧**同源同尺度** | 常规用法，准确率最高 |
| 整屏任意位置 | ②一次框选定稿：框选范围**同时成为监测区域**（位置与大小完全一致），模板即该范围 | 「我框哪就监测哪」，省掉单独框区域这一步 |

两种来源的校验与提示：

- **区域内模式**：模板**大于**监测区域 → 直接拒绝（模板匹配在数学上无法执行）并保留旧模板；占监测区域面积 **>60%** → 告警（相似度接近 1，失去区分度）
- **整屏任意位置模式**：确认后监测区域**被覆盖**为框选范围，状态栏提示所在显示器；因模板＝整块区域（相似度是整块比对），提示把阈值降到 0.5~0.7，想更稳可切回「监测区域内」再框一次更小的标识
- 取消框选 → 监测区域与模板**都不改动**

## 热键

| 键 | 作用 |
|---|---|
| F8 | 暂停 / 继续 |
| F9 | 重置计数 |
| F10 | 退出 |

## 已知限制

- 读的是**屏幕真实像素**，不是游戏内存：监测区域被完全遮挡、游戏最小化、锁屏息屏都会抓不到画面
- DirectX 游戏（如《洛克王国：世界》）无法离屏取画面，离线渲染返回全黑，只能在屏幕上保持可见
- 框选仅支持鼠标所在的单个显示器；跨屏切换请先把鼠标移到目标显示器
- 屏幕分辨率变化后旧坐标会失效，状态栏会提示重新框选
